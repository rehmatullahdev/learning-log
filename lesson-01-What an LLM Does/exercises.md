 Write a short paragraph explaining to a non-technical friend how an LLM works without using words like "neural network", "transformer",
or "AI". Focus strictly on the concept of next-token prediction using a predictive text keyboard analogy (like the one on your smartphone)

My Solution:
An LLM works by predicting the next most possible token, e.g., the word, based on the previous words available. It is like guessing the next number: after you say "1, 2, 3, what's next?", the next most possible digit is 4. Just like that, let's take the example of a smartphone keyboard where we chat every day with our friends and family. 

When we type a word or multiple words, we can see that above the keyboard, there is a section where the keyboard suggests some words that we can use, which are shown according to the previous words we typed. 

For example, if we type "I wake up at 7 AM and then go to ____", then the next possible word could be "brush" or "workout".
